# FitLife Pro — Standalone Fitness & Wellness Website

## No XAMPP required
This is a static front-end project. It runs directly in Chrome/Edge/Firefox or with VS Code Live Server.

### Features
- Modern responsive home page
- Dashboard with steps, water, workouts and streak
- Local browser profile/login demo
- Workout library + category filters
- Workout session starter
- Nutrition and hydration tracker
- BMI calculator
- Educational calorie/BMR estimator
- 30-second workout interval timer
- Wellness habits
- Breathing exercise
- Dark mode
- Mobile navigation
- LocalStorage persistence
- Profile page

## Run without XAMPP
### Option 1: Direct browser
1. Extract the ZIP.
2. Open the `FitLife_Pro` folder.
3. Double-click `index.html`.

### Option 2: VS Code + Live Server
1. Open the `FitLife_Pro` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

### Data
There is no server/database. Profile and tracking values are saved in your browser's LocalStorage.

### Important
The BMI and calorie tools are educational estimates and should not be treated as medical advice. Calorie needs and health decisions vary by individual.
